# 導入マニュアル

**ファミリーマート 納品書・請求書 作成システム**
はじめて入れるときの手順書です。上から順にやれば終わります。

---

## このマニュアルの読み方

**所要時間の目安は40分**です。うち30分は「ステップ7の試運転」で、ここが一番大事です。

| ステップ | 内容 | 目安 |
|---|---|---|
| 1 | Python を入れる | 5分 |
| 2 | システムのフォルダを置く | 3分 |
| 3 | はじめて起動する | 3分 |
| 4 | 画面が出るか確かめる | 1分 |
| 5 | 店舗の一覧を確かめる | 3分 |
| 6 | 売価を確かめる | 5分 |
| 7 | **1日ぶん通してみる（試運転）** | 20分 |
| 8 | 現行のExcelと突き合わせる | 10分 |

> **途中でわからなくなったら、その画面の文字をそのままお知らせください。**
> エラーの英語のメッセージも、写真やコピーでそのまま送っていただければ大丈夫です。

---

## 用意するもの

- **パソコン**（Mac / Windows どちらでも）
- **インターネット接続**（最初の準備のときだけ使います）
- **現行の納品書のExcel** 1日ぶん（ステップ8の突き合わせに使います）

パソコン以外に用意するものはありません。**月額の費用もかかりません。**

> このシステムは**お使いのパソコンの中だけで動きます。**
> クラウドに何かを送ることはなく、外から見られることもありません。

## ステップ1　Python を入れる

このシステムを動かすための土台です。1回入れれば、あとはずっと使えます。

### Mac の場合

1. https://www.python.org/downloads/ を開く
2. 黄色い **「Download Python」** のボタンを押す
3. ダウンロードされた `.pkg` ファイルを**ダブルクリック**
4. 「続ける」を押していき、最後に「インストール」

### Windows の場合

1. https://www.python.org/downloads/ を開く
2. **「Download Python」** のボタンを押す
3. ダウンロードされたファイルを**ダブルクリック**
4. ★**最初の画面の下にある「Add python.exe to PATH」に必ずチェックを入れる**★
5. そのあと「Install Now」を押す

> **ステップ4のチェックを忘れると起動しません。**
> 忘れた場合は、もう一度同じファイルを開いて入れ直してください。

これで、**5つの画面のうち4つ**（ホーム・数量の入力・帳票を作る・売価の変更）が使えます。
残る1つ「FAXから入れる」の準備は**あとまわしで構いません**（→ 巻末の「あとで足す準備」）。

## ステップ2　システムのフォルダを置く

1. お送りしたZIPファイルをダウンロードする
2. **ダブルクリックして展開**する
3. 中にある **`familymart`** というフォルダを、**デスクトップにドラッグ**する

これで `デスクトップ / familymart` ができます。

> **置き場所はデスクトップをおすすめします。**毎日開くフォルダなので、
> すぐ見えるところにあるほうが楽です。あとから動かしても動きます。

フォルダの中には、こういうファイルが入っています。

| ファイル | 何をするもの |
|---|---|
| **起動**（`.command` / `.bat`） | システムを立ち上げる。**毎日使います** |
| **今日の帳票**（`.command` / `.bat`） | 仕分け表と納品書をまとめて作る |
| **月末の請求書**（`.command` / `.bat`） | 請求書を全店ぶん作る |
| **更新**（`.command` / `.bat`） | プログラムを新しくする |
| はじめかた.md | 毎日の使い方 |
| 導入マニュアル.md | このファイル |

> **Macの方は `.command` のほう**、**Windowsの方は `.bat` のほう**を使います。
> 反対のものを開いても何も起きません（壊れることはありません）。

## ステップ3　はじめて起動する

### Mac の場合

**`起動.command` を右クリック** して、出てきた一覧から **「開く」** を選びます。

> ★ **1回目だけは、ダブルクリックではなく「右クリック →『開く』」です。**
> インターネットから取ってきたファイルなので、Macが念のため止めるためです。
> 確認の画面が出たら、もう一度 **「開く」** を押してください。
> **2回目からはダブルクリックで開けます。**

### Windows の場合

**`起動.bat` をダブルクリック**します。

「WindowsによってPCが保護されました」と出たら、
**「詳細情報」→「実行」** を押してください。

### 起動すると何が起きるか

黒い（または白い）文字だけの画面が開き、こう表示されます。

```
  ファミリーマート 納品・請求システム
  ------------------------------------

  Python: Python 3.13.1
  はじめての起動なので、準備をします（1〜2分かかります）...
  必要な部品を確認しています...

  画面を開きます。
  ★ 使っている間、この画面は閉じないでください。
```

**「はじめての起動なので、準備をします」から1〜2分かかります。**
このフォルダ専用の環境を作っているところなので、そのまま待ってください。
（パソコン全体の設定は一切変えません。このフォルダの中だけで完結します）

そのあと**ブラウザが自動で開きます。**

> ★★ **この文字の画面は、使っている間ずっと開いたままにしてください。** ★★
> ここを閉じるとシステムも止まり、ブラウザに「接続が拒否されました」と出ます。
> **終わるときにこの画面を閉じる**、という手順です。

## ステップ6　売価を確かめる

**「売価の変更」** の画面を開いてください。

1. 上のほうで**店舗を選ぶ**
2. その店舗が扱う品目と、**売価・掛け率・原価**が一覧で出る
3. **売価を直すと、原価はその場で計算し直されます**

原価はこの式で自動計算しています。

```
原価（税込） ＝ 売価（税込） × （1 − 掛け率） の小数点切り上げ
```

たとえば宗久グループ（掛け率25%）のバナナ218円なら、
`218 × 0.75 = 163.5` → 切り上げて **164円** です。

**現在入っているのは、いただいた発注書ブックの売価（114品目）です。**
そのあと変わっているものがあれば、ここで直してください。

> 売価は毎週変わるとのことでしたので、**必ずご自身で直せる形**にしてあります。
> まとめて入れ替えたいときは、最新の発注書ブックからの一括取り込みもできます（ご相談ください）。

## ステップ7　1日ぶん通してみる（試運転）★ここが本番

**実際の1日ぶんを、最初から最後まで通してみてください。**
ここで気づいたことが、そのまま本運用の質になります。

### 7-1　数量を入れる

**「数量の入力」** の画面を開きます。

1. **店舗**を選ぶ（まずは国見ケ丘店など1店だけで構いません）
2. **納品日**を選ぶ
3. 品目ごとに**数量**を打ち込む
4. ★**「保存する」を押す**★

> 品目が多いので、**「品目でしぼる」に文字を入れると絞り込めます。**
> 「バナ」と入れればバナナ系だけが残ります。
>
> 高野原店だけは**ロット数**を入れる形です。ロット数を入れると、
> 横に「実数量＝ロット数×最小ロット」が自動で出ます。

**保存を押し忘れると入りません。**必ず押してください。
保存すると、ホーム画面の「今日の入力の状況」がその店舗だけ「入力済み」に変わります。

**入れ直したいとき**は、同じ店舗・同じ納品日をもう一度開いてください。
前に入れた数量が出るので、直して保存し直せば上書きされます。二重には入りません。

### 7-2　仕分け表を出す

**「帳票を作る」** の画面を開き、**納品日**を選んで **「仕分け表を作る」** を押します。

`familymart / output` フォルダに `仕分け表_20260730.xlsx` のようなファイルができます。

開いてみてください。

- **商品が縦、店舗が横**に並んでいます
- **宗久グループと大町2丁目店は同じ1枚**にまとまります（売価が同じため）
- **高野原店様オーナーは別のシート**です（品目も売価も違うため）
- 右端に商品ごとの合計、**最下段に店舗ごとの合計**（積み込みの点検用）
- 商品の並びは**発注書と同じ順**です

> **倉庫でこの1枚を見ながら振り分けられるか**、実際に見て教えてください。
> 並び順を倉庫の動線に合わせて変えることもできます。

### 7-3　納品書を出す

同じ画面で **「納品書を作る」** を押します。

その日に納品する**店舗ぶんがまとめて**できます。

**必ずExcelで開いて、現行の納品書と見比べてください。**

- 罫線・ロゴ・レイアウトが現行のままか
- 宛名が正しいか
- **送料550円が、もらう店舗にだけ入っているか**（高野原店は0円）
- 原価が合っているか

### 7-4　請求書を出す

同じ画面で **締め年月**を選び、**「請求書を作る」** を押します。

**`2026年8月` を選ぶと、2026年7月21日〜8月20日の納品**がまとまります。
（毎月20日締めのため）

できたものを開いて、次を確認してください。

- **納品日ごとに「売上」1行＋「送料」1行**になっているか
- **8%対象と10%対象が分かれている**か（商品が8%、送料が10%）
- 合計金額
- 発行元が **株式会社 工藤祐作商店**、登録番号 **8370001002926** になっているか

ここが合えば導入は完了です。合わなければ、**どの品目がいくら違ったか**を
お知らせいただければ、原因を調べて直します。

> ### ひとつお伝えしておくこと
>
> 現行のExcelを解析したところ、**計算式の誤りが4か所**見つかりました。
> うち1つは**実際に3,878円の請求もれ**、もう1つは**原価が売価を上回る設定**でした。

## 導入後に必ずやっていただきたいこと

### バックアップ

**`familymart / data / shiwake.db`** に、入力した数量がすべて入っています。

**このファイルが消えると、入力したものが全部消えます。**
ときどきUSBメモリやiCloudにコピーしておいてください。

> フォルダごとコピーしておけば確実です。

### 更新のしかた

こちらでプログラムを直したときは、**`更新`（`.command` / `.bat`）** をダブルクリックしてください。

- **入力したデータ（data）はそのまま残ります**
- **設定（config：店舗・商品・売価）もそのまま残ります**
- プログラムと帳票のひな形だけが新しくなります

**ZIPを取り直す必要はありません。**更新のあとは `起動` を開き直してください。

## 毎月自動で請求書を作る（Mac・任意）

慣れてきたら、パソコンに任せることもできます。

1. **「カレンダー」** アプリを開く
2. **毎月21日**に予定を作る（例：「請求書を作る」）
3. その予定を**ダブルクリック**して編集画面を開く
4. 「通知」の欄で **「カスタム」→「ファイルを開く」** を選ぶ
5. 「その他…」から **`月末の請求書.command`** を選ぶ
6. タイミングを **「イベントの時刻」** にする

これで毎月21日に、前月21日〜当月20日ぶんの請求書が自動でできます。

> パソコンの電源が入っていて、ログインしている必要があります。
> できあがったファイルは `output` フォルダに入ります。

**最初のうちは手動（ボタン1回）で回すことをおすすめします。**
自動にするのは、金額が合っていることを何回か確認してからで十分です。

## うまくいかないとき

### Macで「開発元を確認できないため開けません」と出る

`起動.command` を**右クリック →「開く」**で開いてください（ステップ3）。

### Macで「アクセス権がありません」と出る

「ターミナル」アプリを開き、`chmod +x ` と打ち込んでから**半角スペース**を入れ、
`起動.command` をターミナルの窓に**ドラッグ**して、Enterを押してください。

```
chmod +x 起動.command
```

### Macでダブルクリックしても何も起きない

`起動.bat` を開こうとしていませんか。Macは **`起動.command`** のほうです。

### 「Python が見つかりません」と出る

Windowsの場合、インストール時に **「Add python.exe to PATH」** のチェックを
忘れています。もう一度インストーラーを開いて入れ直してください。

### ブラウザが開かない

アドレス欄に `http://127.0.0.1:8765/` を直接入れてください。

### 「接続が拒否されました」と出る

システムが動いていません。順に確認してください。

1. **文字の画面がまだ開いているか** — 閉じているとシステムも止まります
2. **文字の画面に「画面を開きます」まで出ているか** — 準備の途中だとまだつながりません
3. **エラーが出ていたら、その文字をそのままお知らせください**

> 8765番が他のソフトに使われている場合は、8766・8767…と自動でずらして開きます。
> そのときは文字の画面に出ている番号のURLを使ってください。

### 「表を読み取れませんでした」と出る（FAXの画面）

紙が大きく傾いているか、暗すぎます。**真上から、明るいところで**撮り直してください。
「pdftoppm がない」という意味のエラーは、上の poppler の準備がまだです。

## 困ったときの連絡のしかた

うまくいかないときは、次の3つをお知らせいただけると原因がすぐ分かります。

1. **どのステップで止まったか**（例：「ステップ3の起動のところ」）
2. **画面に出ている文字**（写真でもコピーでも構いません。英語のままで大丈夫です）
3. **何をしたときにそうなったか**
