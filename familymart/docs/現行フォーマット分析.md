## 1. 全体の流れ

```
印刷・FAX 発注書  ──→  入力 発注書  ──→  店舗別「納品書」シート  ──→  請求書
（商品マスタ兼        （店舗ごとの列に        （数式で参照するだけ）      （納品日ごとに
  FAX送信用紙）         発注数を入力）                                    1行に集約）
```

1ブックが「商品マスタ」「発注入力」「納品書」を兼ねている。納品日ごとにブックを複製して使っている。

## 2. 価格の決まり方 ★最重要

**すべて税込で計算している。** 単価マスタは持たず、売価と粗利益率から仕入額を毎回計算する。

```
想定税込仕入額 ＝ ROUNDUP( 想定税込売価 × ( 1 − 粗利益率 ), 0 )
```

- **売価** … ファミマ店頭の想定売価。納品書の「単価（売価）」列に出る
- **仕入額（原価）** … マルカが店に請求する額。納品書の「単価（原価）」列、請求書の金額はこちら
- **粗利益率** … 店グループ・商品ごとに違う

| グループ | 粗利益率 |
|---|---|
| マルカ系（仙台高野原・栗生4丁目・仙台上愛子ほか） | 一律 **28%** |
| 宗久グループ（国見ケ丘・大郷山崎・川平1丁目・堤町・広瀬立町ほか） | 商品ごとに **10%** または **25%** |

一部の商品は数式ではなく手入力で仕入額を上書きしている（例: ①のトマト215円、ミニトマト287円）。

## 3. 発注数の入れ方 — 2つの方式がある

| | マルカ系（①③） | 宗久グループ（⑤） |
|---|---|---|
| 入力する値 | **ロット数** | **数量そのもの** |
| 実数量 | `最小発注ロット × ロット数` | 入力値をそのまま合計 |
| 商品情報 | 産地・規格・保存・賞味期限あり | 品名・賞味期限のみ |
| FAX送信用シート | あり（`印刷・FAX 発注書`） | なし |

## 4. 送料550円

`送料` は発注書の最終行（58行目）に固定で置かれ、次の式で自動的に付く。

```
=IF( SUM(その店の発注列) <> 0, 550, 0 )
```

**その日に1品でも注文があれば550円、なければ0円** ＝ 納品1回ごとに550円。
（実装済みの `charge_unit: per_delivery` と一致）

| グループ | 送料 |
|---|---|
| 宗久グループ | **あり**（全店に550円） |
| マルカ系（仙台高野原ほか） | **なし**（式が `550` ではなく `0` になっている） |

②の請求書に550円の行が1つも無いことと整合している。

## 7. 現行ファイルで見つかった不具合

### ★ ② 仙台高野原店の請求書：合計が1日分抜けている

合計式が `=SUM(O21:P32)` になっているが、明細は **33行目まで** ある。

```
明細の実際の合計   53,533 円（13件）
シートの合計       49,655 円
差額               3,878 円  ← 2025/12/20 納品分が請求から漏れている
```

過去の請求書も同じ式なら、同様の漏れが起きている可能性がある。

### ★ ④ 宗久グループの請求書：10%対象の内消費税が過大

`D50 = F50/10` になっているが、`F50` は**税込**金額なので、税込から消費税を出すには **11で割る**のが正しい。

```
10%対象（税込）  3,850 円
現行の内消費税    385 円   （3,850 ÷ 10）
正しい内消費税    350 円   （3,850 ÷ 11）
```

請求金額そのものは変わらないが、インボイスの記載事項である「内消費税」が35円ずれる。
8%側（`D49 = F49-(F49/1.08)`）は正しい。

### 登録番号が2つある

同じ「株式会社 工藤祐作商店」なのに、②と④で登録番号が違う。

- ② 仙台高野原店 … `8370001002926`
- ④ 宗久グループ … `2370001017442`

インボイスの登録番号は事業者ごとに1つなので、どちらかが誤りか、別法人の可能性がある。

### 入力 発注書に重複行がある（マルカ系）

`印刷・FAX 発注書` は商品番号3を欠番にしているが、`入力 発注書` は行数を合わせるため
15行目と16行目が**同じ商品（新玉ねぎ）**を指している。両方に数量を入れると納品書に二重に出る。
