# ファミリーマート 納品書・請求書 作成システム

店舗ごとの納品数量から **納品書** を作成し、**毎月20日締め** で **請求書** を作成します。

納品書・請求書は現行のExcel書式をテンプレートとして読み込み、
罫線・ロゴ・レイアウトを一切崩さずに値だけを流し込みます。

## 注文の入り方は店舗によって違います

| 店舗 | 入り方 |
|---|---|
| 宗久グループ・大町2丁目 | **売り場の画像がLINEに届き、こちらで何を何個入れるか決める**（＝人の判断） |
| 仙台高野原 | **店舗から届くFAXが注文表**（数量が指定されている） |

前者は「注文文面を読み取る」処理ではありません。決めた数量を入力する形になります。

```
売り場画像を見て数量を決める ┐
                              ├→ 納品数量 →（納品日ごと）→ 納品書 →（20日締め）→ 請求書
FAXの注文表（高野原のみ）    ┘
```

## はじめて使うとき

**[はじめかた.md](はじめかた.md)** に、Pythonの入れ方から1日の流れまで手順をまとめてあります。
`起動.bat`（Macは `起動.command`）をダブルクリックすれば、画面がブラウザで開きます。
プログラムを新しくするときは `更新.bat`（Macは `更新.command`）を開きます。
**入力したデータと設定は残したまま**、プログラムだけが入れ替わります。

| 画面 | 用途 |
|---|---|
| **http://127.0.0.1:8765/** | **ホーム**（入口・今日の入力の状況） |
| http://127.0.0.1:8765/nyuryoku | 数量の入力 |
| http://127.0.0.1:8765/fax | FAXから数量を入れる |
| http://127.0.0.1:8765/shorui | 帳票を作る（仕分け表・納品書・請求書） |
| http://127.0.0.1:8765/kakaku | 売価の変更 |

ホームを開けば、あとは画面の案内どおりに進めます。

自分のパソコンの中だけで動き、外からはつながりません。

## セットアップ（コマンドで使う場合）

```bash
cd familymart
pip install -r requirements.txt          # 必須
pip install -r requirements-fax.txt      # FAX読み取りを使う場合のみ
```

### テンプレートの配置

`templates/` に現行の納品書・請求書のExcelを置きます。

```
templates/
├── 納品書.xlsx
└── 請求書.xlsx
```

現行ブックから切り出したものが既に入っています。作り直すときは:

```bash
python3 tools/build_templates.py
```

`templates/現行/` にある現行ブックを読み、帳票シート1枚だけを取り出して、
他シートを参照している数式を空欄化します（罫線・フォント・列幅・印刷設定はそのまま）。
**シート内で完結する数式（金額＝数量×単価、合計、消費税）は残してあるので、
計算は現行どおりExcelが行います。**

## 使い方

すべて `familymart/` ディレクトリで実行します。

```bash
export PYTHONPATH=src   # Windowsは  set PYTHONPATH=src
```

### 1. 納品数量を入力する（入力画面）

```bash
python3 -m fmbill nyuryoku
```

ブラウザが開くので、**店舗と納品日を選んで、品目ごとに数量を打ち込みます。**
売り場の画像を見ながらそのまま入力できます。

- 原価・売価・掛率が各行に出ます。入力すると下に合計と送料が出ます
- ロット制の店舗（高野原店様オーナー）は **ロット数** を入れると実数量が横に出ます
- 品目が多いので「品目でしぼる」に文字を入れて絞り込めます
- 保存済みの日を開き直すと数量が読み込まれ、直して保存し直せます
- 自分のパソコンの中だけで動きます（外からはつながりません）

### 1b. FAXから入れる（高野原店）

入力画面の右上「FAXから入れる」、または `http://127.0.0.1:8765/fax` を開きます。
FAXを写した画像かPDFを選ぶと、**1行ずつ切り出して画面に並べます。**

- 書き込みのある行には色が付きます
- **数字は自動で読み取りません。**切り出した画像を見てご自身で入力します
  （読み違いで請求金額が狂うのを防ぐため、あえて人の目で確認する形です）
- FAXに書かれた数はロット数として扱われます
- 行と商品の対応は選び直せます（用紙の並びが変わっても対応できます）

### 1c. テキストから取り込む

```bash
python3 -m fmbill torikomi 数量.txt

# 保存せず読み取り結果だけ確認したいとき
python3 -m fmbill torikomi 数量.txt --dry-run

# 本文に店舗名や日付が書かれていないとき
python3 -m fmbill torikomi 数量.txt --store KUNIMIGAOKA --date 2026-07-30
```

1つのファイルに複数店舗・複数納品日が混ざっていても自動で振り分けます。

```
国見ケ丘                       ← 店舗（略称・表記ゆれも可）
7/30                           ← 納品日
バナナ 10                      ← 品目と数量（全角/半角どちらでも可）
玉ねぎS 10
胡瓜2本 5
```

高野原店のようなロット制の店舗では、書いた数が **ロット数** として扱われます
（数量 = ロット数 × 最小発注ロット）。

商品マスタに無い品目は **捨てずに取り込み、`★要確認` として印を付けます**。
仕分け帳のその行は黄色で塗られます。

### 1d. 売価を変える

入力画面の「売価の変更」、または `http://127.0.0.1:8765/kakaku` を開きます。

売価は季節や仕入れで毎週変わるので、画面から1品ずつ直せます。
**売価を直すと原価はその場で計算し直されます**（原価＝売価×(1−掛け率) の切り上げ）。
現行のExcelのように「売価を下げたのに仕入額が古いまま」ということは起きません。

掛け率は店舗ごとの設定なので、同じ売価でも店舗によって原価は変わります。
画面上で店舗を切り替えると、その店の原価が出ます。

まとめて入れ替えたいときは `tools/import_products.py` で発注書ブックから取り込み直せます。

### 2. 取り込んだ数量を確認する

```bash
python3 -m fmbill shiwake --month 2026-08
# → output/仕分け帳_202608.xlsx
```

### 3. 仕分け表を作る（倉庫のピッキング用）

```bash
python3 -m fmbill shiwakehyo --date 2026-07-30
# → output/仕分け表_20260730.xlsx
```

その日の納品ぶんを **商品を縦・店舗を横** に並べた1枚にします。

- **売価が同じグループは1枚にまとめます**（宗久グループと大町2丁目は同じ表）
- 品目も売価も違う高野原店様オーナーは別シートになります
- 行の並びは商品マスタ順。発注書と同じ並びなので倉庫で品物を追いやすくしています
- 注文の無い品目は載せません
- 商品マスタに無い品目も落とさず、色を付けて残します（積み忘れを防ぐため）
- 右端に商品ごとの合計、最下段に店舗ごとの合計（積み込みの点検用）
- 見出しと左3列を固定してあるので、横に長くても品名を見ながらたどれます

```
品名        規格  単位  国見ケ丘  堤町  大町２丁目  合計
バナナ            個        10     6         4    20
玉ねぎS           個        10                    10
トマト            個         4               2     6
合計                        86     6         6    98
```

### 4. 納品書を作る

```bash
python3 -m fmbill nouhin --date 2026-07-30              # その日の全店舗ぶん
python3 -m fmbill nouhin --date 2026-07-30 --store KUNIMIGAOKA
# → output/納品書_20260730_国見ケ丘.xlsx
```

### 5. 請求書を作る（20日締め）

```bash
python3 -m fmbill seikyu --month 2026-08
python3 -m fmbill seikyu --month 2026-08 --issue-date 2026-08-22 --due 2026-08-31
# → output/請求書_202608_国見ケ丘.xlsx
```

`--month 2026-08` は **2026/07/21 〜 2026/08/20** が対象です。

## 店舗ごとの違いの設定

**コードは触りません。`config/` のファイルを編集するだけです。**

### config/stores.yaml — 店舗マスタ

```yaml
stores:
  - code: OOSATOYAMAZAKI
    name: ファミリーマート　大郷山崎店
    short_name: 大郷山崎
    group: 宗久グループ
    margin_rate: 0.10          # ← この店だけ掛け率10%
    aliases: [おおさとやまざき]  # LINE/FAXの表記ゆれ

  - code: TAKANOHARA
    name: ファミリーマート　仙台高野原店
    short_name: 仙台高野原
    group: 高野原店様オーナー
    margin_rate: 0.28
    order_unit: lot            # ← ロット数で発注する
    delivery_fee:
      enabled: false           # ← この店だけ送料なし
```

`defaults:` に書いた内容が全店舗の既定値になり、店舗ごとの記述がそれを上書きします。

| 設定できること | キー |
|---|---|
| 掛け率（粗利益率） | `margin_rate` |
| 送料の有無 | `delivery_fee.enabled` |
| 送料の金額（税込） | `delivery_fee.amount` |
| 請求書の送料の品名 | `delivery_fee.label` |
| 発注の入れ方（数量／ロット数） | `order_unit`（`qty` / `lot`） |
| 商品の引き分け | `group` |
| 締め日 | `closing_day` |
| 請求書の宛名の敬称 | `honorific` |
| 納品書の宛名 | `note_name` |
| 表記ゆれからの店舗特定 | `aliases` |
| 店舗独自の商品呼称 | `item_aliases` |
| 使う帳票テンプレート | `delivery_note.template` / `invoice.template` |

### config/products.yaml — 商品マスタ（自動生成）

**このファイルは現行の発注書ブックから自動生成します。**手で書く必要はありません。

```bash
python3 tools/import_products.py \
  "templates/現行/⑥発注書納品書_宗久グループ_0807230.xlsx:宗久グループ" \
  "templates/現行/⑧発注書納品書_大町2丁目店_080801.xlsx:大町2丁目店（別オーナー）" \
  "templates/現行/③発注書納品書_高野原店様オーナー_7.21納品.xlsx:高野原店様オーナー"
```

売価が変わったら、最新の発注書ブックを渡して作り直してください。
そのブックで最も多い粗利益率をグループの既定とみなし、**そこから外れた品目だけ**
`margin_rate` を持たせます。ふだんは店舗の掛け率が効きます。

```yaml
products:
  - code: "宗久-トマト"
    name: "トマト"
    retail_price: 288         # 想定税込売価
    groups: ["宗久グループ"]   # 品目も売価もグループごとに違う
    shelf_life_days: 5
```

### config/aliases.yaml — 表記ゆれ辞書

商品マスタは再生成で上書きされるため、手で育てる表記ゆれはこちらに分けています。

```yaml
item_aliases:
  "宗久-胡瓜2本": [きゅうり, キュウリ, 胡瓜]
```

### config/layouts.yaml — 帳票のセル位置

現行のExcelのどのセルに何を書き込むかの対応表です。実物のセル位置に合わせてあります。
金額・合計・消費税はテンプレートの数式が計算するので、ここには書きません。

```yaml
delivery_note:
  sheet: 納品書
  cells:
    store_name: C8            # 「国見ケ丘店　様」
    delivery_date: C2
    shipping_cost: D71        # 送料の原価
  rows:
    start: 14
    count: 57                 # 14〜70行
    columns:
      line_no: A              # 連番（YAMLでは no: が真偽値になるため line_no）
      item_name: B
      retail_price: C         # 単価（売価）
      cost_price: D           # 単価（原価）
      qty: E
      # F列=金額(売価)、G列=金額(原価) はテンプレートの数式に任せる
```

## 価格の計算

**金額はすべて税込で扱います。**現行のExcelがそうなっているためです。
単価マスタは持たず、想定税込売価と粗利益率（掛け率）から原価を毎回計算します。

```
原価（税込） = ROUNDUP( 想定税込売価 × ( 1 − 粗利益率 ), 0 )
```

| 店舗 | 粗利益率 | 送料 | 発注の入れ方 |
|---|---|---|---|
| 宗久グループ（国見ケ丘・川平1丁目・堤町・広瀬立町・八乙女中央） | 25% | あり | 数量 |
| 大郷山崎 | **10%** | あり | 数量 |
| 大町2丁目（別オーナー） | 25% | あり | 数量 |
| 仙台高野原 | 28% | **なし** | **ロット数** |

「ロット数」の店舗は、注文に書かれた数がロット数です。数量は `ロット数 × 最小発注ロット`。

大町2丁目はオーナーが違いますが、**売価は宗久グループと同じ商品リストを共有**します
（`stores.yaml` の `price_group`）。請求書は店舗ごとに別々に出ます。

## 消費税の扱い

- 食品は **軽減税率8%**、送料は **標準税率10%** で別々に集計します。
- 金額が税込なので、内消費税は税込金額から逆算します。
  8%は `税込 − 税込÷1.08`、10%は `税込 − 税込÷1.1`（＝税込÷11）。
- 送料550円は **納品1回ごと**。その日に1品でも納品があれば550円、なければ0円。
  現行の発注書の `=IF(SUM(店舗の列)<>0,550,0)` と同じ動きです。
- 「仏花」など食品でない品目は標準税率10%として取り込みます。

## データの保存場所

| 場所 | 内容 |
|---|---|
| `data/shiwake.db` | 納品数量の本体（SQLite）。**バックアップ対象** |
| `output/` | 生成した仕分け帳・納品書・請求書 |
| `templates/` | 現行書式のExcelテンプレート |

同じファイルを二度取り込んでも、店舗・納品日・取込元が同じなら重複登録しません。
取り込んだ元のテキストは1行ずつ `raw_text` として保存しているので、後から元の文面を確認できます。
