# はじめかた（テスト運用の手順）

このシステムは**お使いのパソコンの中だけで動きます。**
インターネットにはつながらないので、外から見られることはありません。

> **はじめて入れるときは、先に [導入マニュアル.md](導入マニュアル.md) を
> ステップ1から順に進めてください（所要40分）。**
> このファイルは、導入が済んだあとの「毎日の使い方」です。

---

## 1回だけ、最初にやること

### Windows の場合

**Python を入れる**

1. https://www.python.org/downloads/ を開いて「Download Python」をクリック
2. ダウンロードしたファイルを実行
3. **最初の画面の「Add python.exe to PATH」に必ずチェックを入れてから**「Install Now」

> ここのチェックを忘れると起動しません。忘れた場合は入れ直してください。

**これだけで、4つの画面のうち3つ（数量の入力・帳票を作る・売価の変更）が使えます。**

**FAXのPDFを読む準備**（あとからでも構いません）

1. https://github.com/oschwartz10612/poppler-windows/releases から最新版をダウンロード
2. 適当な場所（例: `C:\poppler`）に展開
3. 展開先の `Library\bin` フォルダを、Windowsの環境変数 `Path` に追加

### Mac の場合

1. https://www.python.org/downloads/ から Python を入れる
2. FAXのPDFを読むなら、ターミナルで `brew install poppler`

> FAX読み取り用の部品が入らなくても、**他の3画面はそのまま使えます。**
> 「FAXから入れる」画面を開いたときだけ、入っていない旨が表示されます。

## 毎回の起動

**Windows は `起動.bat`、Mac は `起動.command`** をダブルクリックします。
（`.bat` はWindows用なので、Macでダブルクリックしても動きません）

黒い画面が出たあと、ブラウザが自動で開きます。
初回はこのフォルダ専用のPython環境を作るので、1〜2分かかります。

**終わるときは、その黒い画面を閉じてください。**

### Mac ではじめて開くとき

ZIPから取り出したファイルは、そのままではMacに止められることがあります。
次のどちらかで開いてください。

**方法1（かんたん）**
`起動.command` を **右クリック →「開く」** を選び、確認画面で「開く」を押します。
2回目以降はダブルクリックで開けます。

**方法2（「アクセス権がありません」と出る場合）**
「ターミナル」アプリを開き、次を打ち込んでEnterを押します。
`chmod +x ` のあとに**半角スペース**を入れてから、`起動.command` をターミナルの窓にドラッグしてください。

```
chmod +x 起動.command
```

そのあとダブルクリックすれば開きます。

うまく開かないときは、ブラウザのアドレス欄に直接入れてください。

```
http://127.0.0.1:8765/
```

## 新しくするとき（更新）

こちらでプログラムを直したときは、**`更新.command`（Windowsは `更新.bat`）**を開いてください。

- **入力したデータ（data）はそのまま残ります**
- **設定（config：店舗・商品・売価）もそのまま残ります**
- プログラムと帳票のひな形だけが新しくなります

ZIPを取り直す必要はありません。開くと自動で最新版を取ってきます。

> 設定に新しい項目が増えた場合は、新しい版の設定が `config_新しい版` フォルダに入ります。
> ふだんは見なくて構いません。必要なときはお知らせします。

**更新のあとは `起動.command` を開き直してください。**

## 画面

**`http://127.0.0.1:8765/` がホーム画面です。**
4つの入口と「今日の入力の状況」（どの店舗が入力済みか）が並びます。
どの画面からもホームに戻れます。

| 画面 | 何をするか |
|---|---|
| **ホーム** | 入口。今日どの店舗が入力済みかが一目で分かる |
| **数量の入力** | 売り場の画像を見て決めた数量を入れる（宗久グループ・大町2丁目） |
| **FAXから入れる** | FAXの写真やPDFを読み込み、1行ずつ見ながら数量を入れる（高野原店） |
| **帳票を作る** | 仕分け表・納品書・請求書を作る |
| **売価の変更** | 売価を直す。原価は自動で計算し直される |

画面の上に並んでいるリンクで行き来できます。

## 1日の流れ

**1. 数量を入れる**

宗久グループ・大町2丁目は「数量の入力」で、店舗と納品日を選んで品目ごとに数量を入れます。
高野原店は「FAXから入れる」でFAXを読み込み、切り出された行を見ながら数量を入れます。

> 入れ終わったら必ず「保存する」を押してください。

**2. 仕分け表を出す**

「帳票を作る」で納品日を選び、仕分け表を作ります。
これを見ながら倉庫で商品を振り分けます。

**3. 納品書を出す**

同じ画面で納品書を作ります。その日に納品する店舗ぶんがまとめて出ます。

**4. 月末に請求書を出す**

「帳票を作る」で締め年月を選び、請求書を作ります。
`2026年8月` を選ぶと **2026/7/21〜2026/8/20** の納品がまとまります。

## まとめて作る（ボタン1回）

画面を開かずに、ダブルクリック1回で帳票を作れます。

| ファイル | すること |
|---|---|
| **今日の帳票**（`.command` / `.bat`） | 今日の納品ぶんの**仕分け表と納品書**をまとめて作る |
| **月末の請求書**（`.command` / `.bat`） | 締め年月を入れると**請求書を全店ぶん**作る。そのままEnterで先月の締め分 |

数量の入力だけは人の判断が要るので画面で行い、**そのあとはボタン1回**で済みます。

---

## 毎月自動で請求書を作る（Mac）

締め日の翌日に、パソコンが自動で請求書を作るようにできます。

1. 「カレンダー」アプリを開く
2. **毎月21日**に予定を作る（例: 「請求書を作る」）
3. その予定を**ダブルクリック**して編集画面を開く
4. 「通知」の欄で「**カスタム**」→「**ファイルを開く**」を選ぶ
5. 「その他…」から **`月末の請求書.command`** を選ぶ
6. タイミングを「**イベントの時刻**」にする

これで毎月21日に、前月21日〜当月20日ぶんの請求書が自動でできます。

> パソコンの電源が入っていて、ログインしている必要があります。
> できあがったファイルは `output` フォルダに入るので、あとで確認してください。

同じやり方で「今日の帳票」を納品日の朝に自動実行することもできます。

## ファイルの置き場所

| フォルダ | 中身 |
|---|---|
| **output** | できあがった仕分け表・納品書・請求書 |
| **data** | 入力した数量の保存先（`shiwake.db`）。**バックアップしてください** |
| **templates** | 納品書・請求書のひな形 |
| **config** | 店舗・商品・売価の設定 |
| **.venv** | このフォルダ専用のPython環境（自動で作られます。触らなくて大丈夫です） |

> `data\shiwake.db` が消えると、入力した数量がすべて消えます。
> ときどきUSBメモリなどにコピーしておくと安心です。

## 困ったとき

**Macで「開発元を確認できないため開けません」と出る**
`起動.command` を右クリック →「開く」で開いてください（上の「Mac ではじめて開くとき」参照）。

**Macでダブルクリックしても何も起きない**
`起動.bat` を開こうとしていませんか。Macは `起動.command` のほうです。

**「Python が見つかりません」と出る**
Python のインストール時に「Add python.exe to PATH」のチェックを忘れています。入れ直してください。

**ブラウザが開かない**
アドレス欄に `http://127.0.0.1:8765/` を直接入れてください。

**「接続が拒否されました」と出る**
システムが動いていません。次を確認してください。

1. **黒い画面がまだ開いているか** — 閉じているとシステムも止まります。開き直してください
2. **黒い画面に「画面を開きます」まで出ているか** — 準備の途中だとまだつながりません
3. エラーが出ていたら、その文字をそのままお知らせください

> ポート8765が他のソフトに使われている場合は、8766・8767…と自動でずらして開きます。
> そのときは黒い画面に出ている番号のURLを使ってください。

**「表を読み取れませんでした」と出る（FAXの画面）**
紙が大きく傾いているか、暗すぎます。真上から明るいところで撮り直してください。
PDFで「pdftoppm がない」という意味のエラーが出る場合は、上の poppler の準備がまだです。

**数量を入れ直したい**
同じ店舗・同じ納品日をもう一度開くと、前に入れた数量が出ます。直して保存し直してください。

**帳票を作り直したい**
同じ日・同じ月でもう一度作れば上書きされます。

**売価が変わった**
「売価の変更」で直してください。原価は自動で計算し直されます。
たくさん変わったときは、最新の発注書ブックからまとめて取り込むこともできます（ご相談ください）。
