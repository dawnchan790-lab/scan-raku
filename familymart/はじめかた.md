# はじめかた（テスト運用の手順）

このシステムは**お使いのパソコンの中だけで動きます。**
インターネットにはつながらないので、外から見られることはありません。

---

## 1回だけ、最初にやること

### Windows の場合

**Python を入れる**

1. https://www.python.org/downloads/ を開いて「Download Python」をクリック
2. ダウンロードしたファイルを実行
3. **最初の画面の「Add python.exe to PATH」に必ずチェックを入れてから**「Install Now」

> ここのチェックを忘れると起動しません。忘れた場合は入れ直してください。

**FAXのPDFを読む準備**（FAXの画面を使わないなら飛ばして構いません）

1. https://github.com/oschwartz10612/poppler-windows/releases から最新版をダウンロード
2. 適当な場所（例: `C:\poppler`）に展開
3. 展開先の `Library\bin` フォルダを、Windowsの環境変数 `Path` に追加

### Mac の場合

1. https://www.python.org/downloads/ から Python を入れる
2. FAXのPDFを読むなら、ターミナルで `brew install poppler`

---

## 毎回の起動

**`起動.bat`（Macは `起動.command`）をダブルクリックするだけです。**

黒い画面が出たあと、ブラウザが自動で開きます。
初回は必要な部品の準備で1〜2分かかることがあります。

**終わるときは、その黒い画面を閉じてください。**

うまく開かないときは、ブラウザのアドレス欄に直接入れてください。

```
http://127.0.0.1:8765/
```

---

## 画面

**`http://127.0.0.1:8765/` がホーム画面です。**
4つの入口と「今日の入力の状況」（どの店舗が入力済みか）が並びます。
どの画面からもホームに戻れます。

| 画面 | 何をするか |
|---|---|
| **ホーム** | 入口。今日どの店舗が入力済みかが一目で分かる |
| **数量の入力** | 売り場の画像を見て決めた数量を入れる（宗久グループ・大町2丁目） |
| **FAXから入れる** | FAXの写真やPDFを読み込み、1行ずつ見ながら数量を入れる（高野原店） |
| **帳票を作る** | 仕分け表・納品書・請求書を作る |
| **売価の変更** | 売価を直す。原価は自動で計算し直される |

画面の上に並んでいるリンクで行き来できます。

---

## 1日の流れ

**1. 数量を入れる**

宗久グループ・大町2丁目は「数量の入力」で、店舗と納品日を選んで品目ごとに数量を入れます。
高野原店は「FAXから入れる」でFAXを読み込み、切り出された行を見ながら数量を入れます。

> 入れ終わったら必ず「保存する」を押してください。

**2. 仕分け表を出す**

「帳票を作る」で納品日を選び、仕分け表を作ります。
これを見ながら倉庫で商品を振り分けます。

**3. 納品書を出す**

同じ画面で納品書を作ります。その日に納品する店舗ぶんがまとめて出ます。

**4. 月末に請求書を出す**

「帳票を作る」で締め年月を選び、請求書を作ります。
`2026年8月` を選ぶと **2026/7/21〜2026/8/20** の納品がまとまります。

---

## ファイルの置き場所

| フォルダ | 中身 |
|---|---|
| **output** | できあがった仕分け表・納品書・請求書 |
| **data** | 入力した数量の保存先（`shiwake.db`）。**バックアップしてください** |
| **templates** | 納品書・請求書のひな形 |
| **config** | 店舗・商品・売価の設定 |

> `data\shiwake.db` が消えると、入力した数量がすべて消えます。
> ときどきUSBメモリなどにコピーしておくと安心です。

---

## 困ったとき

**「Python が見つかりません」と出る**
Python のインストール時に「Add python.exe to PATH」のチェックを忘れています。入れ直してください。

**ブラウザが開かない**
アドレス欄に `http://127.0.0.1:8765/` を直接入れてください。

**「表を読み取れませんでした」と出る（FAXの画面）**
紙が大きく傾いているか、暗すぎます。真上から明るいところで撮り直してください。
PDFで「pdftoppm がない」という意味のエラーが出る場合は、上の poppler の準備がまだです。

**数量を入れ直したい**
同じ店舗・同じ納品日をもう一度開くと、前に入れた数量が出ます。直して保存し直してください。

**帳票を作り直したい**
同じ日・同じ月でもう一度作れば上書きされます。

**売価が変わった**
「売価の変更」で直してください。原価は自動で計算し直されます。
たくさん変わったときは、最新の発注書ブックからまとめて取り込むこともできます（ご相談ください）。
